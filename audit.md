# Security policy

## Supported versions

Only the current default branch and current production deployment are supported.

## Reporting vulnerabilities

Report suspected security or privacy issues privately to `icontact@equis-nexus.com`, consistent with the repository's inherited `SECURITY.md`. Do not use public GitHub issues. Redact credentials and personal data.

## Security expectations

Keep the current site free of authentication claims until a real server-side identity boundary exists, keep secrets server-side, preserve origin and deployment controls, and review dependencies and workflows before release.

# Security & Privacy Remediation Backlog

The standard scan found no validated vulnerabilities in the reviewed current-tree scope. The investor form is a non-submitting preview and no account, session, cookie, analytics, or backend data-collection surface was found.
