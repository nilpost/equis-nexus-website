# Security Policy

## Reporting a vulnerability

Please report suspected security or privacy issues privately to
[icontact@equis-nexus.com](mailto:icontact@equis-nexus.com).

Include the affected page or file, the observed behavior, the potential impact,
and safe reproduction details. Do not publish credentials, investor
information, property records, or exploit details in a public issue.

## Current security scope

The website currently has no user accounts, passwords, sessions, public
database, payment processing, analytics, or form-submission backend. The
investor-access page is an explicitly non-authenticating preview.

Security reports may still concern:

- Accidental disclosure in source or generated pages
- Dependency or build-chain vulnerabilities
- Cross-site scripting or unsafe navigation
- Custom-domain or deployment misconfiguration
- Accessibility behavior that causes a material access problem

## Supported version

Only the version deployed from the `main` branch is supported.
