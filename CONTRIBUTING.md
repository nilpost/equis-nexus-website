# Contributing

This repository is maintained for Equis Nexus and is not currently accepting
external code or content contributions.

Public visibility, if enabled, is intended for transparency and source
inspection. It does not make the project open source and does not grant rights
to reuse its code, design, copy, or visual assets.

Security and privacy concerns should be reported privately according to
[`SECURITY.md`](SECURITY.md), not opened as public issues.

Authorized maintainers should:

1. Create a focused branch.
2. Keep unrelated local files out of the change.
3. Record the source and approval state for factual business or asset content.
4. Run `npm run lint` and `npm test`.
5. Review generated public HTML for confidential information.
6. Open a pull request and merge only after the required content and technical
   approvals.

By submitting an authorized contribution, the contributor confirms that Equis
Nexus may use it as part of this proprietary project and that it does not
contain third-party confidential information.
